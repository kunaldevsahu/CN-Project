[mac1]$ curl -sI http://app.team1.test/api/status | grep -iE '^HTTP|^location'
HTTP/1.1 301 Moved Permanently
Location: https://app.team1.test/api/status

Reading the verbose output: '(304) (OUT), TLS handshake' = TLS record version 0x0304 = TLS 1.3 (not HTTP 304).
'CAfile: /etc/ssl/cert.pem' is LibreSSL's default bundle; our CA is not in it. Apple's /usr/bin/curl also uses the
macOS keychain trust settings: before the CA was trusted the same request failed with curl (60), see edge-move/02.
